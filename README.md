# The Big Brain of Veeda · preview

A clickable preview of a private AI for Veeda Lifesciences, built by Taapti Technologies.

- Live: https://veeda-big-brain-preview.vercel.app
- Everything in it is sample data made up to show how it works. No Veeda data is used, and no AI model is connected: answers are pre-written.
- Single static page (`index.html`), no build step. `vercel.json` and `robots.txt` keep it out of search engines.

Open `index.html` in a browser, or deploy the folder to any static host.
